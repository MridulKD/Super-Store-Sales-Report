# Superstore Sales Report (Power BI Project)

## 📊 Project Overview
This project analyzes **Superstore Sales Data** using Power BI to gain insights into:
- Total Sales, Profit, and Quantity
- Regional and Category-level Profitability
- Yearly and Quarterly Profit Trends
- Sub-category level performance

The report provides an **interactive dashboard** for business decision-making.

## 🚀 Key Features
- **KPIs:** Total Sales, Profit, Quantity
- **Category Analysis:** Profit distribution by product category
- **Regional Insights:** Profit by different regions
- **Sub-Category Drilldown:** Identifies most and least profitable sub-categories
- **Trend Analysis:** Profit trend by year and quarter

## 🛠️ Tools Used
- Power BI Desktop
- Sample Superstore Dataset

---

## 📌 How to Use
1. Clone/download this repo.
2. Open `Superstore_sales_report.pbix` in Power BI Desktop.
3. Interact with the dashboard for insights.
